# PetYogi 🐕 





## 🧘🏻‍♂️AI Meditation App 📱
PetYogi is a mobile journaling app, which uses AI to generate personalized journaling prompts specific to your situation 📝. Based on the answers to your prompts, a custom meditation is generated by using OpenAI to create the script and a trained Text to Meditative Voice model for the audio.

With a UI inspired by Duolingo, PetYogi uses gamification to get the user coming back for daily journaling and meditations but don't forget your streak! 🔥

## 🤔💭 Inspiration  
As someone who meditates regularly, I always look for the video or audio that suits me in the moment and how I'm feeling right now. But often, I'd end up cycling through generic meditations that don't quite land. 

That’s what sparked the idea for PetYogi. I wanted to see how far I could push AI to create meditations that feel truly personal - guided by journaling prompts tailored to your current state of mind. 

---

## 🤷 What it does
- **Emotion Tracking**: Keep track of how you feel day-to-day by selecting from a list of emotions.
- **Personalized journaling**: Start by writing down your stream of thoughts and let PetYogi generate a list of follow-up questions.
- **Custom meditation track**: Let PetYogi create the perfect meditation to fit your situation, with a calm meditative voice.
- **Gamification & Customization**: Meditate daily to keep your streak and collect gems as you meditate to unlock new pet yogis, soundtracks, and backgrounds.

## 🛠️ Tech Stack  
- **Frontend IOS/Android app:** React Native & Expo
- **Backend:** Express Js, AWS ECR, AWS Lambda, Docker
- **Text to meditation voice:** Python - Google Tacotron2, HIFI-GAN, PyTorch, TensorFlow
- **AI-generated journaling questions:** OpenAi API
- **In-App purchases:** RevenueCat

---

## ⚔️ Challenges Faced  
- **Audio Player Implementation**: On the meditation screen, the audio player needs to auto-play the tracks - with a customizable time interval between each sentence. It also needed to allow the user to pause or move back and forth between audio tracks. With this, I needed to handle various edge cases - like a user spamming the previous and next buttons or leaving mid-track - which required handling async operations such as intervals.
- **Handling Cold Starts**: Since I was exposing the ML model via an AWS Lambda endpoint, I needed to handle cold starts which could vary from 5-30 seconds. With provisioned concurrency, I was able to get this down to around 5 seconds - during which PetYogi would play pre-generated intro audio.
- **Training the ML model & Word enunciation**: Initially, I only trained the Google Tacotron2 model with the default vocoder on 600 audio samples. This gave me a grainy, robotic sound. By adding HIFI-GAN, I got the model to perform significantly better. To solve pronunciation issues, I trained a Grapheme-to-Phoneme model and trained/inferred the model on phonemes instead.
